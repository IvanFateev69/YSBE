# YSBE — автоматизация Яндекс Учебника

ИИ-агент решает карточки на [education.yandex.ru](https://education.yandex.ru/uchebnik/main) (информатика, Python) прямо в браузере Chromium: **печатает код посимвольно, как человек**, а не вставляет из буфера обмена. Отвечает на тесты, проходит слайды теории и переходит к следующим карточкам до конца урока.

```
Яндекс Учебник ↔ MCP-сервер (Chromium, Playwright) ↔ ваш ИИ-агент (любой MCP-клиент)
```

## Как это работает

- Локальный MCP-сервер (`server/index.js`) управляет Chromium через Playwright.
- Браузер использует постоянный профиль (`server/.profile/`) — вход в Яндекс выполняется один раз вручную.
- Агент получает только текст задачи и вердикт проверки — минимум токенов.
- Код вводится посимвольно с рандомной задержкой 30–90 мс — для сайта это ручной набор с клавиатуры.
- Код пишется намерено простым, на уровне 7–8 класса, **без комментариев**.

## Требования

- Node.js 18+ и npm
- 1–2 ГБ свободного места (Chromium)

## Установка

### Linux

```bash
# Fedora
sudo dnf install nodejs
# Debian/Ubuntu
sudo apt install nodejs npm

git clone https://github.com/IvanFateev69/YSBE.git
cd YSBE/server
npm install
npx playwright install chromium
# если браузер не запускается из-за системных библиотек:
# sudo npx playwright install-deps chromium
```

### Windows (PowerShell)

```powershell
# Установите Node.js LTS с https://nodejs.org, затем:
git clone https://github.com/IvanFateev69/YSBE.git

```

### macOS

```bash
brew install node
git clone https://github.com/IvanFateev69/YSBE.git
cd YSBE/server
npm install
npx playwright install chromium
```

## Первый вход (один раз)

```bash
cd YSBE/server
npm run login
```

Откроется Chromium со страницей Яндекс Учебника. Войдите в аккаунт (логин, школа, пароль — вводите вы лично в окне браузера). После успешного входа **закройте окно** — сессия сохранится в `server/.profile/`.

## Запуск и использование

1. Запустите своего ИИ-агента из корня проекта (`YSBE/`). Пример для opencode:
   ```bash
   cd YSBE
   opencode
   ```
   Конфиг `opencode.json` уже подключает MCP-сервер `ysbe`.
2. В открывшемся браузере перейдите к уроку (или скажите агенту открыть его).
3. Напишите в чате: **«начинай»**.
4. Агент ответит «хорошо, приступаю к работе» и начнёт решать карточки. Окно браузера можно **свернуть, но не закрывать**.
5. В конце агент пришлёт короткий отчёт: сколько решено и ответы для карточек, которые не удалось пройти автоматически.

## Смена модели или агента

- Модель по умолчанию указана в `opencode.json` (`opencode-go/qwen3.8-flash` — быстрая и дешёвая). Замените значение `model` на любую доступную вам.
- MCP-сервер стандартный (stdio) и работает с любым MCP-клиентом (Claude Code, Cursor и др.): команда запуска — `node server/index.js` из корня проекта.
- Правила поведения агента — в `ysbe/SKILL.md`. Для других агентов скопируйте инструкции из этого файла в их системный промпт/правила.

## Инструменты MCP-сервера

| Инструмент | Назначение |
|---|---|
| `status` | URL и заголовок текущей страницы |
| `read_task` | Тип карточки (code/test/theory) и текст условия |
| `type_code` | Посимвольный ввод кода в редактор (не вставка) |
| `run_code` | Нажать «Запустить» |
| `read_result` | Вердикт проверки (`passed` = кнопка «Ответить» активна) |
| `submit` | Отправить решение (кнопка «Ответить») |
| `answer` | Ответ на тест: выбор варианта или ввод текста |
| `screenshot` | Снимок карточки в `server/tmp/` (агент удаляет после чтения) |
| `next_task` | Следующая карточка; `done`, когда урок пройден |

## Решение проблем

| Проблема | Что делать |
|---|---|
| Капча или просьба войти снова | `npm run login` и войти заново |
| «редактор не найден» / «кнопка не найдена» | Сообщить агенту — он сделает `screenshot`, или обновите селекторы в `server/index.js` |
| Окно закрыли случайно | Просто продолжите диалог — браузер переоткроется, сессия сохранена |
| Агент пишет слишком сложный код | Проверьте, что загружен скилл `ysbe` (он задаёт стиль 7–8 класса без комментариев) |

## Приватность

- Логин, пароль и номер школы **никогда не хранятся в репозитории** — только в локальном профиле браузера `server/.profile/`, который исключён из git (`.gitignore`).
- Скриншоты в `server/tmp/` удаляются агентом сразу после использования.
