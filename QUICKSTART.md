# Быстрый старт

```bash
git clone https://github.com/IvanFateev69/YSBE.git
cd YSBE/server
npm install
npx playwright install chromium
npm run login        # войдите в Яндекс в открывшемся окне, затем закройте окно
```

Затем из корня проекта:

```bash
cd YSBE
opencode             # или ваш MCP-агент
```

В чате: **«начинай»** — агент приступит. Окно браузера можно свернуть, но не закрывать.

Подробности и решение проблем — в [README.md](README.md).
