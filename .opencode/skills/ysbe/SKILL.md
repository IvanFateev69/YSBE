# YSBE: решение карточек Яндекс Учебника

## Триггер и поведение в чате

- Пользователь пишет «начинай» → ответь ровно: «хорошо, приступаю к работе». Больше ничего.
- Во время работы НЕ пиши пояснений, рассуждений и промежуточных сообщений. Не печатай код в чат. Экономь токены.
- По окончании — один короткий отчёт: «решено N (код: X, тесты: Y)» + список пропущенных карточек с готовыми ответами для ручного ввода.

## Цикл работы

1. `status` — убедись, что открыт урок. Если открыта главная страница — скажи пользователю открыть урок и жди.
2. `read_task` — получи тип карточки и условие.
3. По типу:
   - `code`: реши задачу → `type_code` → `run_code` → `read_result`. Если ошибка — исправь (максимум 2 попытки), затем пропусти и запомни ответ для отчёта.
   - `test`: реши → `answer` (option или text) → при наличии кнопки проверки — `run_code` → `read_result`.
   - `theory` или непонятный тип: при необходимости `screenshot`, прочитай файл, сразу удали его. Если карточку можно пройти (кнопка «Далее») — проходи. Если требуется ответ, который нельзя ввести — запомни ответ и напиши его в финальном отчёте.
4. `next_task` — если `done`, переходи к отчёту. Иначе повтори с шага 2.

## Правила кода (строго!)

- Python, уровень 7–8 класса: переменные, `input()`/`print()`, `if/elif/else`, `for`/`while`, списки, строки, `int`/`float`/`str`/`len`/`range`/`append`/`split`.
- ЗАПРЕЩЕНО: комментарии (`#`), функции `def` (если не требуются условием), list comprehension, lambda, f-строки, импорты (кроме явно требуемых), `enumerate`/`zip`/тернарные операторы, «умные» однострочники.
- Имена переменных простые: `a`, `b`, `n`, `s`, `x`, `spisok` или слово по смыслу.
- `print(a, b)` вместо f-строк. Ввод: `n = int(input())`.
- Код должен выглядеть так, будто его писал школьник 13–14 лет: прямолинейно, без изящества.

## Ограничения

- Никогда не используй буфер обмена и программную вставку в редактор — только `type_code` (он печатает посимвольно).
- Не изменяй файлы проекта, кроме удаления скриншотов из `server/tmp/`.
- Окно браузера не закрывать (сворачивать можно).
